# Driver Delivery Support Assistant

A Flask-based web application designed to help delivery drivers handle common delivery-related queries and receive quick support suggestions.

## Features

- Driver query input
- Automatic issue classification
- Priority detection
- Suggested support response
- Recommended action
- Clean and responsive web interface
- Smooth CSS animations

## Technologies Used

- Python
- Flask
- HTML
- CSS

## How It Works

```text
Driver Query
     ↓
Query Analysis
     ↓
Issue Category
     ↓
Priority Detection
     ↓
Suggested Response
     ↓
Recommended Action
Supported Query Types
Customer Issues
Delivery Location Issues
Vehicle Issues
Delivery Delays
Order Cancellations
General Queries
Installation

Clone the repository:

git clone https://github.com/jegatheshthalakku-sys/driver-delivery-support.git
cd driver-delivery-support

Create a virtual environment:

python3 -m venv venv
source venv/bin/activate

Install Flask:

pip install flask
Run the Application
python3 app.py

Open your browser:

http://127.0.0.1:5000
Example Query
Customer is not answering my call

The system provides:

Issue Category: Customer Issue
Priority: High
Suggested Response
Recommended Action
